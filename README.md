# 对话大纲 + 提示词库

一个 Chrome 浏览器扩展，为 **Claude**（claude.ai）和 **ChatGPT**（chatgpt.com）网页版添加：

- **多级目录**：按每次提问分组，展开显示回答里的各级标题，点击即可跳转。
- **星标**：给重要的提问加星，可以只看标了星的提问。
- **提示词库**：保存常用提示词，一键插入到输入框，支持 `{{变量}}` 和 `//` 快速插入。

所有数据只保存在你自己的浏览器里，不会发送到任何服务器。

## 安装

1. 下载本项目并解压（或 `git clone`）。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择本项目文件夹（里面有 `manifest.json` 的那一层）。
5. 打开或刷新 claude.ai 或 chatgpt.com，右侧会出现面板。

Edge 等基于 Chromium 的浏览器同样可以用这种方式安装。

更新代码后，在 `chrome://extensions` 里点扩展卡片上的刷新按钮，再刷新网页即可。

## 使用

### 目录

| 操作 | 说明 |
|---|---|
| 点提问文字或标题 | 跳转到对应位置 |
| 1级 / 2级 / 3级 / 全部 | 设置目录显示到第几级标题（层级按每个回答里的最高一级标题算起） |
| 每行左侧的箭头 | 单独展开或折叠 |
| 顶部的展开/折叠按钮 | 一次性全部展开或折叠 |
| 搜索按钮 | 在提问和标题中搜索 |
| 提问右侧的星星 | 鼠标移到提问上会出现，点一下标记，再点取消 |
| 只看标记 | 只显示标了星的提问 |

滚动页面时，目录会高亮当前所在的标题。星标按对话分别保存。

### 提示词库

- **新建**：点“提示词”页右上角的 `+`。标签用逗号分隔，一条提示词可以有多个标签。
- **变量**：在内容里写 `{{期刊}}` 这样的变量，插入或复制时会弹出小框让你填写，并记住上次填的值。
- **插入**：点“插入”会放进输入框，不会自动发送，可以继续修改。
- **快速插入**：在 Claude 或 ChatGPT 的输入框里输入 `//` 加关键词，比如 `//润色`，用 ↑↓ 选择，回车插入，Esc 关闭。
- **备份**：右上角的导出/导入按钮，可以把提示词保存成 JSON 文件，或在另一台电脑导入。

### 快捷键

`Alt + O`（Mac 上是 `Option + O`）：打开或收起面板。

## 已知限制

- 只能用于浏览器里的网页版，Claude 和 ChatGPT 的桌面 App 不加载浏览器扩展。
- Claude 和 ChatGPT 的网页结构可能会更新，导致目录抓不到内容或找不到输入框。这时通常只需要修改 `content.js` 顶部 `SITES` 里的选择器。
- 目录只显示页面上已经加载的消息。Claude 和 ChatGPT 都会在滚动时卸载远处的消息，所以长对话的目录不完整，内容和编号会随滚动变化。

## 项目结构

```
manifest.json   扩展配置（Manifest V3）
content.js      全部功能：读取对话、目录、星标、提示词库、// 快速插入
icons/          扩展图标
DESIGN.md       设计说明（功能规格与实现要点）
```
